# Accretion texture

`accretion-vortex.png` is the original luminance sprite created using the built-in image generation tool for this project. The user supplied fiery red and violet black-hole references as visual direction. The game colours this single monochrome texture dynamically, retaining blue player fields, varied alien fields, and icy white-hole plasma.

The source image is 1254 × 1254 pixels. The source core centre is approximately UV (0.496, 0.4825). `accretion.gdshader` maps that source to the actual gameplay radius, masks the inner disk, and animates rotation/radial turbulence using the paused simulation clock. Mipmaps preserve fine filaments at phone size. The generated black background becomes transparent through the shader's luminance mask; it is not a screenshot of a starfield.

## Generation prompt

Use case: stylized-concept. Asset type: one production 2D game VFX texture, square 1024x1024. Create a spectacular face-on black hole accretion vortex on a pure black background, centered exactly at the middle of the square. This is a luminance texture to be recolored blue/cyan, fiery red/gold, or violet in a live game shader, so use only grayscale silver-white light and black: no colors. It should have the realistic fine turbulent plasma detail of a cinematic black-hole wallpaper: dense wispy flowing gas, hundreds of hair-thin luminous filaments, brighter braided burning inner streams, uneven twisting spiral arms, wispy smoke and occasional tiny embers swept along the spiral. A perfectly circular pitch-black empty event horizon at the exact center, radius exactly 14 percent of the image width (diameter 28 percent). A dazzling but detailed thin white photon rim just outside the core with asymmetric bright flare, flowing outward into several natural sweeping logarithmic spirals. Bright material concentrated between 15 and 30 percent radius, thinner wisps reaching 43 percent radius, then a smooth fade to completely black before the outer 8 percent margin. View straight down the disk so the center is circular, no tilt or side view. The vortex must be richly organic and fibrous, not evenly spaced lines, not flat geometric ribbon strips, not a perfect uniform ring. Similar to a dense fiery red-orange vortex or electric violet accretion disk rendered in luminous grayscale. No text, labels, borders, watermark, stars, planet, ship, background scene, lens flare cross, or rocks. Keep all outer edges pure black and avoid any cropping; this is an isolated VFX sprite for a game.

No CLI/API fallback was used. The generated original remains in the image-generation output directory; the game loads this committed workspace copy.
