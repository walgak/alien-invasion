Built-in image-generation tool, one reference-conditioned call per asset. Each full prompt consists of the shared text followed by the corresponding primary request below. Generated alpha was copied intact into the project.

## Shared text

Use case: stylized-concept
Asset type: isolated high-detail 2D game boss sprite for a top-down space shooter.
Input image: design reference only. Recreate ONLY the large main boss / top view, not the surrounding sheet.
Composition: exactly one centered boss, perfectly face-on orthographic view, symmetrical around a vertical axis, entire silhouette in frame with 7 percent empty margin on all sides. Square image. Dense polished painted detail readable at 260px size.
Materials: convincing baked metal/rock reflections, highlights and deep layered bevels. Keep outer silhouette crisp. The ring segments are physical disconnected components with clear background gaps.
Background: genuinely TRANSPARENT alpha including all gaps between the floating armor pieces. No background stars, space, nebula, floor, shadow plane, gradients, fog behind the object, labels, text, watermark, other objects, loose debris or additional views. No exhaust plume. NO full-frame light beams. Keep glow restrained closely to object. Preserve reference design faithfully.
